Public, no-password API for creating customized QR codes. Same rendering engine as the editor. Works locally or on a deployed Node/Docker server.

POST /api/v1/qr

GET /api/v1/qr

GET /qr/custom

The /qr/customdata, size, file and config parameters for easy migration. Not all original proprietary style names are exactly identical.

POST JSON example

POST https://your-domain.com/api/v1/qr
Content-Type: application/json

{
  "data": "https://example.com/q/stand-001",
  "size": 1000,
  "file": "svg",
  "download": false,
  "config": {
    "body": "rhombus",
    "eye": "frame13",
    "eyeBall": "ball14",
    "bodyColor": "#294D2B",
    "bgColor": "#FFFFFF",
    "gradientColor1": "#294D2B",
    "gradientColor2": "#64A83D",
    "gradientType": "linear",
    "gradientOnEyes": false,
    "logoMode": "clean"
  }
}

Call from another app

const response = await fetch('https://YOUR-SERVER/api/v1/qr', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    data: 'https://example.com/q/stand-001',
    file: 'png',
    size: 1000,
    config: {body: 'dots', eye: 'frame11', eyeBall: 'ball12', bodyColor: '#294D2B'}
  })
});
if (!response.ok) throw new Error(await response.text());
const qrImageBlob = await response.blob();
const url = URL.createObjectURL(qrImageBlob);
document.querySelector('#qr-preview').src = url;

Deploy & security

Login is deliberately removed. Anybody with access to a publicly deployed server can use the editor and the API. Protect the service using a network gateway / Cloudflare Access and production rate limiting if this should remain private.

SVG works in Node immediately. For PNG, install librsvg2-bin (rsvg-convert) or Inkscape on the host; the included Dockerfile provides the rasterizer. GitHub Pages can host the editor but does not run the Node API.

The design engine is independently implemented, and not affiliated with or licensed by QRCode Monkey. Styles are similar to the screenshot, not pixel-identical reproductions of proprietary assets.
